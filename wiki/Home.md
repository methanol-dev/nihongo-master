## ⚡ BẮT ĐẦU NHANH (QUICKSTART)

1. **Khởi chạy ứng dụng ngay tại máy:**
   ```bash
   git clone https://github.com/methanol-dev/nihongo-master.git
   cd nihongo-master
   npm start
   ```
2. **Truy cập vào trình duyệt:** `http://localhost:3300`
