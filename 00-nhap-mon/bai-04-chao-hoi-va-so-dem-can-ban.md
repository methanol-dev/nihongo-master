# 🤝 BÀI 04: CHÀO HỎI GIAO TIẾP & SỐ ĐẾM CƠ BẢN

> **Mục tiêu**: Giao tiếp tự tin các câu chào hỏi thường nhật, nắm vững hệ thống số đếm từ 0 đến 100.000 trong tiếng Nhật.

---

## 1. CÂU CHÀO HỎI THƯỜNG NHẬT (AISATSU 挨拶)

| Tiếng Nhật | Hiragana | Romaji | Ý nghĩa & Hoàn cảnh sử dụng |
| :--- | :--- | :--- | :--- |
| **おはようございます** | おはようございます | Ohayou gozaimasu | Chào buổi sáng (Lịch sự). Bạn bè thân thiết dùng: *Ohayou* |
| **こんにちは** | こんにちは | Konnichiwa | Chào buổi trưa / chiều (Chào chung từ 10h sáng - 5h chiều) |
| **こんばんは** | こんばんは | Konbanwa | Chào buổi tối (Sau khi trời sập tối) |
| **おやすみなさい** | おやすみなさい | Oyasuminasai | Chúc ngủ ngon (Lịch sự). Bạn bè dùng: *Oyasumi* |
| **ありがとうございます**| ありがとうございます | Arigatou gozaimasu | Cảm ơn rất nhiều (Trang trọng). Thân mật: *Arigatou* |
| **すみません** | すみません | Sumimasen | Xin lỗi (khi làm phiền) / Cảm ơn khi được giúp đỡ / Gọi phục vụ |
| **ごめんなさい** | ごめんなさい | Gomennasai | Xin lỗi (Khi bản thân phạm sai lầm) |
| **いただきます** | いただきます | Itadakimasu | Câu nói trước khi ăn cơm ("Tôi xin phép nhận bữa ăn") |
| **ごちそうさまでした** | ごちそうさまでした | Gochisousama deshita | Câu nói sau khi ăn xong ("Cảm ơn vì bữa ăn ngon") |
| **はじめまして** | はじめまして | Hajimemashite | Rất hân hạnh được gặp lần đầu tiên |
| **よろしくおねがいします** | よろしくおねがいします | Yoroshiku onegaishimasu | Rất mong nhận được sự giúp đỡ của bạn |

## 2. HỆ THỐNG SỐ ĐẾM CĂN BẢN (0 - 99)

| Số | Chữ Hán | Hiragana | Romaji | Lưu ý đặc biệt |
| :---: | :---: | :--- | :--- | :--- |
| 0 | 零 | ゼロ / れい | zero / rei | |
| 1 | 一 | いち | ichi | |
| 2 | 二 | に | ni | |
| 3 | 三 | さん | san | |
| 4 | 四 | **よん / し** | yon / shi | Trong đếm số thường dùng **よん** |
| 5 | 五 | ご | go | |
| 6 | 六 | ろく | roku | |
| 7 | 七 | **なな / しち** | nana / shichi | Thường dùng **なな** |
| 8 | 八 | はち | hachi | |
| 9 | 九 | **きゅう / く** | kyuu / ku | Thường dùng **きゅう** |
| 10 | 十 | じゅう | juu | |

### Công thức ghép số hàng chục:
- `11` = 10 + 1: `じゅういち` (juuichi)
- `20` = 2 x 10: `にじゅう` (nijuu)
- `45` = 4 x 10 + 5: `よんじゅうご` (yonjuugo)
- `99` = 9 x 10 + 9: `きゅうじゅうきゅう` (kyuujuukyuu)

## 3. CÁC HÀNG SỐ LỚN (TRĂM - NGHÌN - VẠN)

- **Trăm (百 - Hyaku)**:
  - 100: `ひゃく` (hyaku)
  - 300: `さんびゃく` (san**byaku** - Biến âm)
  - 600: `ろっぴゃく` (ro**ppyaku** - Biến âm xúc âm)
  - 800: `はっぴゃく` (ha**ppyaku** - Biến âm xúc âm)
- **Nghìn (千 - Sen)**:
  - 1.000: `せん` (sen)
  - 3.000: `さんぜん` (san**zen** - Biến âm)
  - 8.000: `はっせん` (ha**ssen** - Xúc âm)
- **Vạn (万 - Man = 10.000)**: *Lưu ý: Tiếng Nhật phân tách 4 chữ số (đơn vị Vạn)*
  - 10.000: `いちまん` (ichiman - 1 vạn)
  - 50.000: `ごまん` (goman - 5 vạn)
  - 100.000: `じゅうまん` (juuman - 10 vạn)
